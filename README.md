# محاسبه‌گر لات بر اساس ریسک - پلاگین cTrader (WebView)

این پروژه یک **WebView Plugin** برای cTrader است (کار می‌کند روی دسکتاپ، وب و **موبایل**، چون این نوع پلاگین‌ها روی هر سه پلتفرم ساپورت می‌شوند — برخلاف اکسپرت‌های MT که فقط روی دسکتاپ اجرا می‌شوند).

## این پلاگین چه کاری می‌کند
1. به اکانت باز شما در cTrader وصل می‌شود (بدون نیاز به لاگین جدا؛ سشن خودِ cTrader استفاده می‌شود).
2. قیمت لحظه‌ای (Bid/Ask) نماد انتخابی را می‌گیرد.
3. شما فقط **قیمت Stop Loss** و **مقدار ریسک به دلار** را وارد می‌کنید.
4. لات سایز را طوری محاسبه می‌کند که اگر قیمت به SL برسد، ضرر شما دقیقاً برابر همان مبلغ دلاری باشد؛ با تغییر قیمت لایو بازار، محاسبه هم زنده آپدیت می‌شود.
5. با دکمه Buy/Sell سفارش مارکت را با همان لات و همان SL باز می‌کند.

## مراحل راه‌اندازی
```bash
npm install
npm run dev      # تست لوکال
npm run build    # خروجی نهایی در پوشه dist
```
1. پروژه build‌شده (پوشه `dist`) را روی یک هاست وب (مثلاً Vercel, Netlify, Cloudflare Pages) دیپلوی کنید تا یک URL عمومی بگیرید.
2. در cTrader (وب یا ویندوز) بروید به بخش ساخت پلاگین (Plugin builder) و URL سایت‌تان را وارد کنید تا پلاگین ساخته شود.
3. محل نمایش پلاگین روی موبایل را در تنظیمات پلاگین انتخاب کنید (مثلاً داخل صفحه معامله).
4. پلاگین را در گوشی enable کنید.

## نکات مهم و محدودیت‌ها (حتماً بخوانید)
- **فرمول فعلی ساده‌سازی‌شده است:** فرض شده ارز حساب شما همان ارز quote نماد است (مثلاً حساب دلاری روی EURUSD یا XAUUSD). برای جفت‌ارزهای کراس (که ارز quote با ارز حساب فرق دارد)، باید یک مرحله‌ی تبدیل نرخ اضافه اضافه شود (از طریق درخواست symbol تبدیل) — این بخش در کد با کامنت `TODO` مشخص شده و پیاده نشده، چون به داده‌ی زنده‌ی حساب شما نیاز دارد.
- مقادیر `minVolume` / `stepVolume` / `maxVolume` و `lotSize` را از پاسخ `getSymbol` می‌خواند تا لات نهایی با قوانین بروکر شما هماهنگ باشد؛ پیشنهاد می‌شود قبل از استفاده‌ی واقعی، روی حساب دمو تست کنید.
- این کد یک نسخه‌ی پایه و قابل توسعه است، نه محصول نهایی تست‌شده در همه شرایط بازار (اسپرد، اسلیپیج، سشن‌های کم‌نقدینگی و غیره را در نظر نگرفته).
- مسئولیت هرگونه معامله و ریسک مالی صرفاً بر عهده‌ی خود شماست؛ قبل از استفاده روی حساب واقعی حتماً روی دمو تست کنید.
